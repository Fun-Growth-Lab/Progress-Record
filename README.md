# 研究進捗アプリ

研究チーム向けの進捗・タスク管理・連絡アプリ（スマホ縦向き用のWebアプリ）。
構成は Mathgames と同じ：`index.html` 1枚 ＋ Supabase（fetchでREST直接呼び出し）＋ GitHub Pages。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて入り） |
| `supabase-setup.sql` | Supabase に流すテーブル作成＋パスワード設定のSQL |
| `supabase-admin.sql` | 管理者機能（メンバーの非表示・復元）を追加するSQL。setup のあとに1回実行 |
| `supabase-edit.sql` | 記録を編集したときに、変更前の内容を履歴として残すためのSQL。1回実行 |
| `supabase-admin-password.sql` | 管理者パスワードを変更するSQL（1行）。必要になったときに実行 |
| `supabase-admin-badge.sql` | 管理者マーク＋連絡の相手の制限（同じチームか管理者のみ）のSQL。`supabase-admin.sql` のあとに1回実行 |
| `supabase-teams.sql` | チームをメンバー0人でも残す／チームの削除を管理者だけにするSQL。`supabase-admin.sql` のあとに1回実行 |
| `supabase-archive.sql` | チームの「アーカイブ」と「完全に削除」を使うためのSQL。`supabase-teams.sql` のあとに1回実行（パスワードの書き換えは不要） |
| `supabase-delete.sql` | メンバー（管理者を含む）を完全に削除できるようにするSQL。`supabase-admin.sql` のあとに1回実行（パスワードの書き換えは不要） |
| `supabase-events.sql` | 予定（試合の日など）のためのSQL。`supabase-setup.sql` のあとに1回実行（パスワードの書き換えは不要） |
| `manifest.json` / `sw.js` / `icon-*.png` | ホーム画面に追加するための設定・アイコン |

## セットアップ（最初の1回だけ）
1. https://supabase.com で **新しいプロジェクト**を作る（リージョンは Tokyo）。
2. 左メニュー **SQL Editor** → New query に `supabase-setup.sql` を貼り付け、
   `'ここにパスワード'` をチーム全員で使うパスワードに書き換えて **Run**。
   - 半角英数字12文字以上を推奨。
   - パスワードを変えたいときは、同じSQLのパスワード部分だけ変えてもう一度 Run。
3. **Project Settings → API**（または Connect）で **Project URL** と **publishable key** を控える。
4. `index.html` 先頭付近の `CONFIG` に貼る：
   ```js
   const CONFIG = {
       url: 'https://xxxxxxxx.supabase.co',
       key: 'sb_publishable_xxxxxxxx'
   };
   ```
5. このフォルダを GitHub の新しいリポジトリに置き、Settings → Pages で公開する。
   （publishable key は公開されても問題ありません。データはパスワード一致のときだけ読み書きできます）

## 管理者（制作者用）
アカウントには **一般** と **管理者** の2種類がある。管理者は、どのチームにも所属せず、全チームを管理する。
1. `supabase-admin.sql`（管理者パスワード）と `supabase-admin-badge.sql`（管理者マーク）を SQL Editor で実行しておく。
2. 初めて使うとき、パスワードの次のアカウント選択の画面で、**「メンバーとして新規登録」**（名前とチームを登録）か **「管理者として新規登録」**（チームには所属しない）を選ぶ。すでにある管理者のアカウントは、一覧の「管理者」から選ぶと、「管理者ログイン」画面でパスワードを入力する（「パスワードを表示」あり・間違えたときは画面に理由が出る・左上の矢印で戻れる）。管理者は、名前 → 管理者パスワード の順に入力して登録する。
3. 管理者パスワードは、**登録のとき、または新しい端末で管理者アカウントを初めて選ぶときの1回だけ**。その端末には保存され、以後は聞かれない（設定に「管理者モード」の切り替えはない）。
4. 管理者には名前の横に「管理者」マークが付き、他の人からも見える。
5. **管理者パスワードの変更**：`supabase-admin-password.sql` の `'新しい管理者パスワード'` を書き換えて SQL Editor で Run。古いパスワードはすぐ使えなくなり、各端末は次に管理者アカウントを選ぶときに新しいパスワードを聞かれる。

### 管理者にできること
- **チームの切り替え**：タスク・記録・連絡の画面の一番上に、見ているチームの名前（▾）が出る。タップすると、下から縦の一覧が出て、選べる（現在のチームにチェック、チームが多いときは絞り込み検索つき）。選んだチームは3つのタブで共通で、次に開いても保たれる。
- **タスク／記録タブ**：選んだチームを閲覧。入力欄・＋ボタン・編集はなく、閲覧専用。「全チーム」のとき、**タスクと予定は全チームぶんが一度に並ぶ**（チーム名つき）。記録は、チームの選択画面になり、チームを選ぶまで中身は出ない。
- **メッセージタブ**：選んだチームのメンバーの一覧から、個人を選んで、その人とのやり取りを開く。「全チーム」では、未読・管理者・各チームのメンバーが並ぶ。
- **新規メッセージ**：チームごとにまとめて全員の名前が並び、最初は全員にチェック。「全員付ける」「全員外す」、チーム名の横のチェック（そのチーム全員の付け外し）、個人ごとの付け外しができる。届き方は、一人ひとりへの個別メッセージ（その人とのメッセージの履歴にも入る）。
- **設定 → チーム管理**：チームの作成・名前の変更・アーカイブ・復元・完全な削除（すべて管理者だけ）、チーム画面のメンバーへの「メッセージ」。
- **設定 → メンバー管理**：メンバーの非表示・元に戻す（記録は消えない）と、**完全な削除**（`supabase-delete.sql` を実行した場合）。削除は管理者アカウントも対象で、その人のタスク・記録・メッセージも一緒に消え、元に戻せない。「まとめて選んで削除」で、複数の人をチェックして一度に削除できる（テスト用のアカウントの掃除など）。自分自身を削除したときは、アカウント選択に戻る。

## チーム
- 「設定」→「チーム」で、**チームの作成・参加・移動・脱退・チーム名の変更**ができる（全メンバー可）。
- **記録・タスクは個人に属する**。チームを移ると、過去の分も含めて一緒に移り、元のチームからは見えなくなる。脱退（所属なし）中は自分の分だけが見える。
- チーム名を変えると、メンバー全員とチームの連絡に反映される（他の端末も自動で追随）。
- チームチャット（グループの部屋）はない。メッセージは、人と人の間の個別メッセージだけ。過去のチームチャットの履歴はデータベースに残るが、画面には出ない。
- チームは「チーム表」に残るので、**メンバーが0人になってもチームは存続**する（`supabase-teams.sql` を実行した場合）。
- **アーカイブ**（管理者だけ）：チームを一覧・メッセージ・チーム選択から見えなくする。メンバーは「所属なし」になり、記録・タスク・メッセージは残る。「チーム管理」の「アーカイブ済み」から**復元**できる（メンバーは0人で戻る）。
- **完全に削除**（管理者だけ・アーカイブ済みのチームのみ・チーム名の入力が必要）：チームをデータベースから消す。元に戻せない。メンバーの記録・タスク・メッセージは個人のものなので消えない。
- アーカイブ済みのチームと同じ名前では、新しくチームを作れない（復元するか、別の名前にする）。

## メッセージのルール
- 送れる相手は、**同じチームの人と管理者だけ**。一般のメンバーは、自分のチームの人と管理者に送れる。管理者は全員に送れる（サーバー側でも制限）。
- **新規メッセージ**：一般のメンバーは、自分のチームの人と管理者の名前が最初から並び（全員にチェック済み）、外したい人だけ外して送る。チームをまたいだ選択（全チームの全員の一覧）は管理者だけ。
- **メッセージを見る**：メッセージタブで人を選ぶと、その人との会話（チャット形式）が開き、履歴を見ながら返信できる。自分と相手の会話だけが見える（他の人同士の会話は見えない）。管理者が「全員」に送ったメッセージも、その人との会話に入る。
- メッセージタブに**赤い未読マーク**が付き、ブラウザのタブ名にも「●」が付く。会話を開くと消える。

## テーマ
「設定」→「テーマ」で背景と色のセットを選べる（8種類・端末ごとに保存。初期はソラライズド）。
Nord / Catppuccin / Tokyo Night / Dracula / Gruvbox / Solarized の公式パレットが元で、
文字の読みやすさ（WCAG 4.5:1）を満たすよう調整してある。

## 使い方
- 最初にパスワードを入力 → 名前とチームを登録（2回目以降は自動）。
- 別の端末では、パスワード入力後に一覧から自分の名前を選ぶ。
- iPhone：Safariで開く → 共有 → 「ホーム画面に追加」／Android：Chromeメニュー → 「ホーム画面に追加」。

## 使い方の説明（チュートリアル）
- はじめて使うアカウント（一般・管理者とも）には、最初に**使い方の説明**が出る。タブの使い方、チームの選び方（管理者は、画面上部のチーム名▾）などを、数枚のカードで紹介する。「次へ」「戻る」・横にスワイプ・「スキップ」ができる。
- 一度見る（またはスキップする）と、その端末では、そのアカウントに対しては再表示されない。「設定」→「使い方を見る」で、いつでももう一度見られる。

## 画面（下のタブ）
- **タスク**：「進行中／期限切れ／完了」の3つに分けて表示（破棄したタスクは表示されない）。3つのボタンが件数の表示を兼ねる（期限切れが1件以上あると、数字が赤くなる）。進行中は期限ごとにまとめる。チーム全員のタスクを表示。自分の担当には「自分」の目印が付く。上のボタンで「自分」「チーム全員」を切り替えられる（記録タブと同じ形式）。誰のタスクも作成・担当変更できる
- **予定**：試合の日などを「あと○日」で見せる（カレンダーではなく、タスクと同じ見せ方）。「これから／終了」の切り替え、「開催中・今日／7日以内／それ以降」のまとまり、右に大きく日数。複数日（合宿など）は終了日を入れると「○日目」と表示。一般のメンバーは**自分のチームの予定**を追加・編集・削除できる（右下の＋、行をタップで編集）。管理者が予定を作るときは、チームがチェックボックスで並び（最初は全チームにチェック、「全部付ける」「全部外す」あり）、チェックしたチームそれぞれに同じ予定が作られる。「全チーム」の表示では全チームの予定がチーム名つきで並ぶ。編集・削除は、チームごとの予定を1つずつ行う。タスク画面の一番上には、次の予定が1行出る（`supabase-events.sql` を実行した場合）
- **記録**：日付ごとのメモだけ（タスクの履歴は出さない）。「日／週／月」で期間を切り替え（選んだ日を最後の日として、1日／7日間／30日間）。「自分／チーム全員」の切り替えつき。自分の記録は編集でき、変更前の内容は「編集済」から見られる（`supabase-edit.sql` を実行した場合）
- **メッセージ**：チームの人・管理者との個別メッセージ（チャット形式・約6秒ごとに自動更新・未読バッジつき）
- **設定**：名前変更、テーマ、CSVダウンロード、管理者モード、アカウント切替

## 注意
- 個人あてメッセージは、パスワードを知っている人が技術的にはDB経由で読めます（本格的な秘密通信ではありません）。
- Supabase無料プランは **1週間まったくアクセスがないと一時停止**します（ダッシュボードから再開）。
  自動バックアップもないので、大会前などにCSVで定期的に保存してください。
- 通知（プッシュ通知）はありません。アプリを開いているときだけ自動更新されます。
