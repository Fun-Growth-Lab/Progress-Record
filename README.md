# ロボ研究ノート

ロボカップチームの研究記録・タスク管理・連絡アプリ（スマホ縦向き用のWebアプリ）。
構成は Mathgames と同じ：`index.html` 1枚 ＋ Supabase（fetchでREST直接呼び出し）＋ GitHub Pages。

## ファイル
| ファイル | 役割 |
|---|---|
| `index.html` | アプリ本体（HTML/CSS/JSすべて入り） |
| `supabase-setup.sql` | Supabase に流すテーブル作成＋パスワード設定のSQL |
| `manifest.json` / `sw.js` / `icon-*.png` | ホーム画面に追加するための設定・アイコン |

## セットアップ（最初の1回だけ）
1. https://supabase.com で **新しいプロジェクト**を作る（リージョンは Tokyo）。
2. 左メニュー **SQL Editor** → New query に `supabase-setup.sql` を貼り付け、
   `'ここにパスワード'` をチーム全員で使うパスワードに書き換えて **Run**。
   - 半角英数字12文字以上を推奨。
   - パスワードを変えたいときは、同じSQLのパスワード部分だけ変えてもう一度 Run。
3. **Project Settings → API**（または Connect）で **Project URL** と **publishable key** を控える。
4. `index.html` 先頭付近の `CONFIG` に貼る：
   ```js
   const CONFIG = {
       url: 'https://xxxxxxxx.supabase.co',
       key: 'sb_publishable_xxxxxxxx'
   };
   ```
5. このフォルダを GitHub の新しいリポジトリに置き、Settings → Pages で公開する。
   （publishable key は公開されても問題ありません。データはパスワード一致のときだけ読み書きできます）

## 使い方
- 最初にパスワードを入力 → 名前とチームを登録（2回目以降は自動）。
- 別の端末では、パスワード入力後に一覧から自分の名前を選ぶ。
- iPhone：Safariで開く → 共有 → 「ホーム画面に追加」／Android：Chromeメニュー → 「ホーム画面に追加」。

## 画面
- **タスク**：自分のタスク（期限順・期限切れは赤）
- **みんな**：チーム全員のタスク（人で絞り込み）。誰のタスクも作成・担当変更できる
- **きろく**：日付ごとのメモ＋その日のタスク進捗（自分／みんな）
- **連絡**：チーム全体チャット＋個人あてメッセージ（約6秒ごとに自動更新、未読バッジつき）
- **その他**：名前変更、CSVダウンロード（期間・自分/全員を指定）、ログアウト

## 注意
- 個人あてメッセージは、パスワードを知っている人が技術的にはDB経由で読めます（本格的な秘密通信ではありません）。
- Supabase無料プランは **1週間まったくアクセスがないと一時停止**します（ダッシュボードから再開）。
  自動バックアップもないので、大会前などにCSVで定期的に保存してください。
- 通知（プッシュ通知）はありません。アプリを開いているときだけ自動更新されます。
